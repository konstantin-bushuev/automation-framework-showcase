# Общая архитектура и взаимодействие модулей

Для фреймворка реализована мультимодульная структура: независимые модули api, web, android и общий модуль core.

Корневой файл build.gradle.kts содержит общие настройки проекта, а также централизованно подключает общую папку config в качестве источника тестовых ресурсов для модулей. 
Каждый модуль имеет собственный файл build.gradle.kts, в котором содержатся настройки, специфичные для этого модуля.

Такая структура:
* Обеспечивает гибкую настройку каждого модуля независимо от остальных
* Упрощает добавление новых модулей и отключение неиспользуемых
* Снижает вероятность конфликтов в настройках и коде при параллельной работе нескольких инженеров
* Обеспечивает возможность независимого запуска тестов отдельных модулей

## Взаимодействие модулей

* CORE - общий модуль, содержащий функциональность, доступную для использования другими модулями
* API, WEB и ANDROID - модули, которые могут использовать функциональность CORE, но не зависят друг от друга
* CONFIG — общая папка с properties-файлами. Не является отдельным модулем. Подключается в качестве источника тестовых ресурсов для модулей, содержащих тесты.

```text
                            ┌───────────────┐
                            │    CONFIG     │
                            │  (properties) │
                            └───────┬───────┘
                                    │
             ┌────────────────────────────────────────────────┐
             │         │            │            │            │
             ▼         ▼            ▼            ▼            ▼
        ┌─────────┐
        │  CORE   │
        └────┬────┘
             │
             └──────────────────────────────┐
                                            │
                       ┌──────────────────────────────────────┐
                       │             │           │            │
                       ▼             ▼           ▼            ▼
                  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐
                  │   API   │  │   WEB   │  │ ANDROID │  │   ...   │
                  └─────────┘  └─────────┘  └─────────┘  └─────────┘
```
