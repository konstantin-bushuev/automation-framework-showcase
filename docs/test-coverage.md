# Покрытие тестированием

* *M - ручное тестирование*
* *A - автоматизированное тестирование*
* *M+A - тестирование частично вручную и частично автоматически*

#### Примеры тестирования функциональностей для пользователя

| Функциональность|API| Web |Android|
|-|-|-|-|
| Регистрация и подтверждение email|A     |M+A|M+A|
| Авторизация по имени/email|A      |M+A|M+A|
| Восстановление пароля|A |M+A|M+A|
| Управление активными сессиями|A|M+A|M+A|
| Обновление/ротация токенов|A |-|-|
| Управление настройками профиля|A|M+A|M+A|
| Прохождение игры|A|M+A|M+A|

### Распределение автоматизированных и ручных проверок

API-тесты автоматизированы в полном объёме.

Автоматизация UI-тестов преимущественно направлена на проверку функционального поведения интерфейса:
- выполнение пользовательских сценариев
- корректность взаимодействия с элементами
- наличие элементов, необходимых для выполнения функциональности
- корректность переходов

Ручное тестирование UI преимущественно направлено на визуальную составляющую интерфейса:
- корректность вёрстки и расположения элементов
- соответствие дизайн-макетам
- адаптивность вёрстки
- другие визуальные особенности
