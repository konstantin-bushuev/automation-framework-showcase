# Структура модулей

* Core - общие ресурсы и конфигурации
* API - API-автоматизация
* Web - Web-автоматизация 
* Android - Android-автоматизация 

## Модуль Core

```text
project/core/
├── settings.gradle.kts           
└── src/main/java/.../core/            
    ├── config/         # Config - чтение .properties               
    ├── data/           # Общие константы приложения
    └── users/          # Модель и конфигурация тестовых пользователей
```

## Модуль API

```text
project/api/
├── settings.gradle.kts           
└── src/main/java/.../api/   
                                  # --Служебные пакеты--
    ├── config/                   # ApiConfig        
    ├── filters/                  # Фильтры для вариантов доступа    
    ├── session/                  # Сессии пользователей 
    ├── utils/                    # Вспомогательные методы
    ├── core/                     # Общие API-компоненты и ресурсы          
                   
    │                             # --Функциональные пакеты--
    ├── auth/                     # Регистрация, авторизация
    ├── profile/                  # Профиль пользователя
    ├── games                     # Игры
    │   ├── <game name>/            
    │   └── <game name>/          
    └── ...                       # другие функциональные пакеты
   
   
├── src/test/resources/      
             ├── images/        
             ├── audio/                      
             └── ...


└── src/test/java/.../api_tests/
                      ├── auth/                     
                      ├── profile/                 
                      ├── games                     
                      │   ├── <game name>/            
                      │   └── <game name>/          
                      └── ...
```

#### Общая структура функциональных пакетов

Функциональные пакеты (auth, profile, <game name> и другие) могут содержать следующие пакеты в зависимости от потребностей конкретной функциональности:

```text
      ├── models/             # Модели данных           
      ├── clients/            # Управление HTTP-запросами и получение ответов
      ├── services/           # Обработка ответов и преобразование данных 
      ├── dto/                # Дополнительные форматы передачи данных
      ├── data/               # Генерация тестовых данных
      └── assertions/         # Проверки
```
